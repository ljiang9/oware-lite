# oware-lite

极简 Oware（播棋）引擎：2×6 坑、逆时针播种、2/3 子吃子、大满贯保护、断粮喂子规则，带贪心 AI。纯 Python 标准库。

## 玩法

```
      北 (AI)
  [ 4][ 4][ 4][ 4][ 4][ 4]
  [ 4][ 4][ 4][ 4][ 4][ 4]
    1   2   3   4   5   6
      南 (你)
```

- 你是南家（下方），输入 1–6 选择己方坑位走子。
- 每回合从己方非空坑抓起全部种子，逆时针逐坑播一子（播满一圈时跳过起点坑）。
- 最后一子若落在对方一侧且该坑变为 2 或 3 子，吃掉该坑，并向后连续吃掉对方一侧所有 2/3 子的坑。
- **大满贯保护**：一次能吃光对方全部种子时，本次吃子作废。
- **断粮规则**：对方一侧无子时，必须走能送子的走法；若无子可送，对局结束，轮走方拿走剩余全部种子。
- 先拿到 25 子即胜；否则子多者胜，24–24 和棋。

## 运行

```bash
python3 -m oware_lite            # 人机对战（你是南家）
python3 -m oware_lite --auto --games 10 --seed 42   # AI 对 AI 演示
python3 -m oware_lite --auto --games 5 --seed 7 --verbose  # 打印每步
```

## 诚实局限

- AI 只是贪心（吃子数优先），不做深层搜索；熟悉规则的人类通常能赢。
- 400 半回合上限防无限循环，撞上限后双方各拿走己侧剩余种子（真实对局极少见）。
- 文本界面，无图形/存档/悔棋；Python 3.10+。
